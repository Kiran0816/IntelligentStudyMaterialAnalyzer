# 📚 Intelligent Study Material Analyzer

An AI-powered web application that helps students analyze study materials by generating summaries, extracting keywords, creating quizzes, answering questions, and providing voice-based assistance.

## 🚀 Features

- 📄 Upload PDF documents
- 📝 Automatic text extraction (OCR support)
- 📖 AI-generated document summaries
- 🔑 Keyword extraction
- 🎯 Difficulty analysis
- ❓ Question Answering (QA) system
- 🧠 Automatic MCQ generation
- 🎙️ Speech-to-Text support
- 🔊 Text-to-Speech support
- 🤖 AI-powered conversational assistant
- 🌐 URL content analysis

## ⚙️ Installation

### Clone the repository

```bash
git clone https://github.com/Kiran0816/IntelligentStudyMaterialAnalyzer.git
```

### Navigate to the project

```bash
cd IntelligentStudyMaterialAnalyzer
```

### Install dependencies

```bash
pip install -r requirements.txt
```

### Run the application

```bash
python app.py
```
